# S級コーチ（入口ノート）

ロードバイクのトレーニングと減量の前提知識をまとめた入口です。まずこのノートを読み、必要なノートをリンクからたどってください。

## 目標
- **富士ヒル**：70分（2026年11月に75分から変更）→ 最終65分（54.6kg時）
- **FTP**：257W → 280W（2026/11/15のFTPテストで+2W。最新値はIntervals.icu）
- **体重**：段階目標 60kg → 57kg → 54.6kg（最終は175cm・60kgと同じBMI19.6）。各段階に到達したら14日間維持してから次へ
- **W′**：22kJ設定
- サブ目標：2027年1月の駅伝3.3km（13分前後）

## 今の方針（2026年11月〜）
- パワー優先の減量：高強度の日と、その前日は食べる。楽な日で赤字を取る
- 週2回の高強度（月曜は閾値走とVO2maxを隔週、水曜はJETTレース）、1回の中強度、週1回のロングZ2（3時間）、残りは緩め

## 1週間の型
| 曜日 | 内容 |
|---|---|
| 月 | 高強度（閾値走 ⇄ VO2max 隔週）2時間枠 |
| 火 | Z2 1時間（子供を見る日は休み） |
| 水 | JETTレース 2時間枠 |
| 木 | Z2 1時間（休みの日あり） |
| 金 | 2時間枠（中強度・SSTなど） |
| 土 | Z2 1時間（休みの日あり） |
| 日 | ロングZ2 または FTPテスト 2時間枠以上 |

- 練習は超早朝（起床15分後にスタート）。夕食18時ごろ、就寝20時ごろ

## 道具
- Zwift（Cycplus T7）→ Intervals.icu / Strava → アプリ「S級コーチ」で日報を生成 → Claudeのプロジェクト「トレーニング」
- 食事はカロミルでPFC管理（トレーニング補給はカロミルに入れない）
- 体重は毎日記録、Intervals.icuのウェルネスに入る

## ルール
- 新しいノートは本当に必要なときだけ作る。基本は既存のノートに追記する
- 数字が変わったら、このノートの「目標」も直す
