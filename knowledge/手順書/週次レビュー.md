# 週次レビュー（月曜）

[入口へ戻る](../S級コーチ.md)

アプリが月曜の日報に「📊 週次レビュー」を出す。隔週で判定と提案が出る。

1. 体重の7日平均の変化と、収支からの予測を比べる
2. 判定（アプリが計算）
   - 増えている（+0.2kg以上）→ 赤字+100kcal
   - 横ばい（±0.2kg以内）→ 赤字+50kcal
   - 順調に減っている → 据え置き
   - 減るのが速すぎる（週0.5kg超）→ 赤字−50kcal
   - 維持期間中・記録不足・維持の日が多い → 判定なし
3. 提案を採用するときは、Claude Codeのチャットで「採用」と伝える。コードの赤字の値を直してもらう
4. その週に分かったことを[学びの記録](../学びの記録.md)に追記する
5. 目標の数字（FTP・体重）が変わっていたら、[入口のノート](../S級コーチ.md)を直す
