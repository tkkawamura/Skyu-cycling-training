# 指標の読み方（自分用の基準）

[入口へ戻る](S級コーチ.md)

## コンディション（朝）
| 指標 | 良い | 注意（疲労のサイン） |
|---|---|---|
| 安静時心拍 | 39bpm前後＝シーズンベスト級、40〜43＝良好 | 28日平均より+5bpm以上 |
| HRV | 28日平均以上 | 28日平均より15%以上低い、または45ms未満 |
| 睡眠スコア | 75以上（目安） | 60未満 |
| フォーム（TSB） | −10〜−20（練習が積めている） | −25以下 |

- 注意が1つでも出たら、その日は維持（赤字0）にする。アプリが自動で判定する
- HRVと安静時心拍は、絶対値ではなく自分の28日平均と比べる

## ライド
| 指標 | 意味 | 見方 |
|---|---|---|
| NP / CP比 | 強度 | SSTは0.88〜0.94、閾値走は0.95〜1.0 |
| EF（NP÷平均心拍） | 有酸素の効率 | 同じメニューで前回より高ければ伸びている |
| デカップリング（Pa:HR） | 後半の心拍の上がり方 | **プラス＝後半に心拍が上がった（悪化）**。Z2は5%未満が目安、5%以上は疲労・暑さ・補給不足を疑う |
| W′bal | 無酸素の貯金の残り | 20%以下の時間が長いと、その後の持久力が落ちる |
| 心拍のZ | 体の負担 | SSTは心拍150〜155くらいが今の目安 |

- デカップリングは2026/11/27にアプリの符号の向きを直した。それより前のアプリの値は、プラスとマイナスが逆
- 「前回の同じメニューとの比較」で、EFとデカップリングの変化を見るのが一番わかりやすい
